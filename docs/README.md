# CoursePath documentation

Project notes for CoursePath, a symbolic-AI course planner (Streamlit + SQLite). The
top-level `README.md` is the user-facing guide; these pages record *how* and *why* the
project is built the way it is.

| Page | What it covers |
|---|---|
| [decisions.md](decisions.md) | Every place the build deviates from or interprets the assignment spec, with reasons |
| [architecture.md](architecture.md) | Module layout, data flow, database schema, reasoning pipeline |
| [catalog.md](catalog.md) | The course catalog, graduation rules, and the three demo profiles |
| [development.md](development.md) | Setup, Makefile targets, testing, linting, git workflow |
| [progress.md](progress.md) | Milestone status and commit log |
